Smart Travel Planner

A Java travel-management application built for my Object-Oriented Programming II course. It manages clients, trips, transportation, and accommodations, calculates trip costs, saves records, and generates a dashboard.

Team course project with Taminda Ait Ouazzou.

Built with: Java · JFreeChart · HTML/CSS · CSV

View source ↗ View sample dashboard ↗

Modeling a trip

A trip connects a client, a transportation option, and an accommodation. Abstract Transportation and Accommodation classes hold shared behavior, while flights, trains, buses, hotels, and hostels implement their own pricing rules.

calculateTotalCost() combines the trip's base price with the selected objects' costs through polymorphism. Copy constructors and copy() methods create independent copies of nested objects.

Interfaces give the application consistent contracts for identifiers, billing, and CSV serialization.

Data handling

Reusable generics

Repository<T> handles ID lookup, Predicate<T> filtering, and Comparable sorting across entity types. Trips can be filtered by destination or cost range; clients can be sorted by spending.

Dynamic ArrayList collections replace fixed-size arrays. A generic RecentList<T> uses a LinkedList to keep the ten most recent items, adding at the front and removing the oldest at the back.

CSV persistence

GenericFileManager<T> shares save/load logic through the CsvPersistable interface. Stored type markers reconstruct the correct transport or accommodation subclass.

After loading, the service resolves stored IDs back into client, transportation, and accommodation references, restoring the relationships between objects.

Validation & exceptions

Custom exceptions report invalid client, trip, transportation, and accommodation data, duplicate emails, and missing entities. File and relationship errors are handled with messages and an error log.

A predefined scenario exercises object creation, cost calculations, equality checks, deep copies, and exception cases.

From Java objects to a dashboard

The application passes its client and trip records to the included dashboard and visualization helpers. JFreeChart exports bar, pie, and line charts for trip costs, destinations, and durations.

The generated HTML/CSS report brings those charts together with client and trip tables, average cost, average duration, total trip costs, and the most visited destination.

This preview uses two sample trips to Paris and Berlin. The dashboard generator is credited in the source to Kaustubha Mendhurwar.
