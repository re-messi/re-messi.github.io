Smart Travel Planner

A Java app for organizing travelers and trips, calculating costs, and saving travel records. Built for my Object-Oriented Programming II course, it also generates a dashboard to compare trips at a glance.

Team course project with Taminda Ait Ouazzou.

Built with: Java · JFreeChart · HTML/CSS · CSV

View source ↗ View sample dashboard ↗

Putting a trip together

Each trip connects a traveler with a way to get there and a place to stay. The app adds the trip's base price to the transport and accommodation costs, using the pricing rules for the selected flight, train, bus, hotel, or hostel.

The different travel options share common code while handling their own prices. Copying a trip also creates separate copies of its travel details, so changing the copy leaves the original intact.

Shared rules for identifying records, calculating prices, and saving files keep the different parts of the app consistent.

Keeping track of the details

Finding and comparing trips

Trips can be filtered by destination or budget, and travelers can be sorted by how much they've spent. The app also keeps a list of the ten most recently added records.

The lists grow as records are added. Search and sorting features reuse the same underlying code across different kinds of records.

Saving travel records

Travel records can be saved to CSV files and loaded again later, including the details specific to each type of transport or accommodation.

When reopening them, the app reconnects each trip to the right traveler, transport, and place to stay, keeping the plan intact.

Handling mistakes

The app checks for invalid details, duplicate email addresses, and missing records. It reports problems with loading files or connecting records and keeps an error log to help trace them.

The project includes sample scenarios for calculating costs, comparing records, copying trips, and handling errors.

Reading the dashboard

The dashboard brings travel records into tables and charts. You can compare trip costs, see where travelers are going, and check how long each trip lasts.

It also shows average costs and trip lengths, total costs across trips, and the most visited destination, so the main information is easy to find.

This preview uses two sample trips to Paris and Berlin. The project uses an included dashboard generator by Kaustubha Mendhurwar.
